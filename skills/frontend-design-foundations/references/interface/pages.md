# Interface: marketing pages, docs and long-form

Read with [interface.md](interface.md) when the work is a marketing page, documentation, a blog or a changelog.

- The hero must communicate what it is, who it is for, why it matters, and what to do next before the page gets clever.
- Use one primary CTA. Logged-out CTAs should acquire users; logged-in CTAs should take them back to the product.
- No disconnected parallax. No auto-advancing carousel for primary content. Scroll-linked effects must map directly to user movement and clarify structure; otherwise cut them.
- Intro animation can play once per session, then skip.
- Product demos load fast, poster cleanly, respect reduced motion, and never block the CTA.
- Docs need visual examples, not just code. Code snippets need copy buttons. Docs should expose markdown when useful: copy-as-markdown and `.md` routes for AI and tooling workflows.
- Blogs and changelogs should have RSS feeds.
