## Rules

1. Do not use external game knowledge.
2. First record neutral observations; then measurements; then claims/models.
3. Every temporal claim cites actual source PTS and context.
4. Every number includes measurand, unit, method, uncertainty, count, and scope.
5. Retain contradictions and alternatives.
6. Return typed unknowns rather than guessing.
7. Do not read the emerging report thesis unless this is an adversarial/presentation role.
8. Return proposed evidence-ledger rows, not a new private ontology.
9. For a high-impact model fork, state what supplied-footage event could distinguish the candidates.
