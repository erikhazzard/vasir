# Controlling-Idea Method

## 1. The Irreducible Equation

> **[GLOBAL GENRE VALUE AT END] + [CHIEF STORY-SPECIFIC CAUSE]**

The genre reference controls the first term. The story controls the second.

A complete internal causal model is:

> Under **conditions C**, a **specific causal agent D** pursues **object G** through **strategy S**, chooses **value A over competing value B**, pays **cost K**, takes **climactic action X**, and therefore changes the global genre value from **starting pole V₁** to **ending pole V₂**.

The final sentence should compress this model without deleting its causal meaning.

## 2. Distinguish the Terms

- **Subject:** a topic such as freedom, love, justice, or honor.
- **Thematic territory:** a value conflict such as freedom versus duty.
- **Thematic question:** an unresolved question the story investigates.
- **Counter-idea:** the strongest credible causal answer opposed to the final answer.
- **Controlling-idea hypothesis:** a proposed Value + Cause statement used while designing.
- **Controlling idea actually proved:** the Value + Cause statement inferable from the finished climax and resolution.
- **Crisis:** incompatible alternatives.
- **Climax:** enacted answer.
- **Resolution:** consequences.

## 3. Character and Controlling Idea Are Intertwined

Define the protagonist’s:

- Conscious object of desire.
- Subconscious need or internal deficit.
- Initial value state.
- Governing fear.
- Gift or capacity.
- False or incomplete theory of action.
- Initial strategy.
- Arc type: positive change, steadfast, corruption, disillusionment, or failed change.

Define the antagonist’s:

- Mutually exclusive object of desire.
- Theory of how the world works.
- Effective strategy.
- Partial truth.
- Blind spot.
- Reason not to yield.

The antagonist is a competing theory of action, not merely an obstacle.

## 4. Form the Thematic Field

Create:

1. **Thematic question:** neutral and open.
2. **Controlling-idea hypothesis:** genre value + proposed cause.
3. **Counter-idea:** strongest opposed causal claim.
4. **Truth in each side:** what each correctly sees.
5. **Blind spot in each side:** how each can be misused.
6. **Conditions:** where each appears to work.
7. **Tradeoff:** what meaningful good must be surrendered.
8. **Narrative stance:** what the story depicts, endorses, rejects, mourns, or leaves uneasy.

One clear final position is compatible with exploring every serious facet of the question.

## 5. Value Spectrum

Use the selected genre file’s operational spectrum:

- Positive.
- Contrary.
- Contradictory.
- Negation of the negation.

Ask:

- Who embodies each state?
- Which strategy produces each state?
- What does the antagonist falsely present as positive?
- What does the protagonist mistake for the positive?
- What is the deepest compound negative possible in this story?

The negation of the negation is a value-depth tool, not a mandatory third-act synthesis.

## 6. Philosophy-to-Drama Translation

Do not begin with a philosopher’s name. Begin with the human problem.

1. Human problem.
2. Accurate proposition from a source.
3. Action implication.
4. Real benefit.
5. Failure mode.
6. Strong counter-position.
7. Character embodiments.
8. Dramatic test.
9. Climactic implication.
10. Plain-language compression.

Philosophy can deepen the Cause and counter-idea. It cannot replace the global genre Value.

## 7. Build a Genuine Crisis

For each option specify:

| Test | Option A | Option B |
|---|---|---|
| Good protected |  |  |
| Duty honored |  |  |
| Beneficiary |  |  |
| Value sacrificed |  |  |
| Irreversible cost |  |  |
| Why reasonable |  |  |
| Identity created |  |  |
| Moral residue |  |  |

Reject the crisis when:

- One option obviously dominates.
- One option is not possible.
- The protagonist lacks enough knowledge to own the choice.
- A costless third option is visible.
- Both options are merely tactics serving the same value.
- The choice cannot alter the global genre value.

### Third Ways

A third way is valid only if:

- The binary was a false frame created by the antagonist, institution, or protagonist’s flaw; or
- The third action was causally prepared; and
- It pays the cost of both options or sacrifices a different but equally meaningful good.

Reject loopholes, hidden rescues, technicalities, surprise powers, and deus ex machina.

## 8. Separate Crisis, Climax, and Resolution

### Crisis

> Preserve the witness and allow an innocent execution, or expose the witness and stop the execution while making the witness a certain target.

### Climax

> The prosecutor reveals the witness publicly and uses her own protected identity as bait to draw out the killer.

### Resolution

> The execution stops and the killer is exposed, but the witness dies and the prosecutor loses the office whose protections made the plan possible.

Only after all three exist can the controlling idea be validated.

## 9. Multi-Axis Value Accounting

Track:

| Dimension | Possible charge |
|---|---|
| External/global | The genre-defined value at the story level |
| Internal | Integrity, wisdom, self-respect, corruption, despair, etc. |
| Interpersonal | Intimacy, trust, estrangement, betrayal, kinship |
| Social/extrapersonal | Institutional legitimacy, communal safety, political power, ecological order |

A strong ironic ending may be:

- External win / internal loss.
- External loss / internal win.
- Life preserved / moral identity destroyed.
- Freedom won / belonging lost.
- Justice exposed / punishment denied.
- Victory achieved / honor forfeited.

The global controlling idea still uses the selected genre’s value axis.

## 10. Story-Wide Exploration

### Beginning

- Establish value deficit and object of desire.
- Show why the initial strategy appears reasonable.
- Let the counter-idea produce early evidence.
- Dramatize or naturally articulate the thematic question.

### Early and Middle Build

- Escalate through action/reaction.
- Let the initial strategy produce success and cost.
- Give the antagonist genuine victories.
- Expose misuse or limits of the controlling idea.
- Turn scenes on relevant values.

### Midpoint

- Reinterpret the conflict.
- Reveal the counter-idea’s partial truth.
- Complicate the binary.
- Increase the cost of both choices.

### Late Build / All Is Lost

- Threaten or enter the negation of the negation.
- Make the initial strategy impossible to continue innocently.
- Strip away easy solutions.
- Prepare every capacity used in the climax.

### Ending

- Crisis forces value priority.
- Climax enacts it.
- Resolution preserves the sacrifice and turns the genre value.
- Final image embodies the controlling idea without explanation.

## 11. Causal Proof Tests

### Removal Test

If the protagonist’s climactic action is removed, does the final global value state still occur? If yes, identify the real cause.

### Counterfactual Test

Would the other crisis choice produce a materially different global charge? If no, the crisis is theatrically false.

### Setup/Payoff Test

Does the climax use a capacity, relationship, insight, object, or sacrifice established earlier?

### Agency Test

Did the protagonist or named causal agent actively create the outcome, or merely survive an outcome created by luck, rescue, fate, or antagonist error?

### Genre Payoff Test

Does the ending deliver the loaded genre reference’s core event and resolve its object of desire?

### Cost Test

Does the resolution preserve rather than erase the promised sacrifice?

## 12. Negative Endings

Strong negative causes include:

- Refusal of needed change.
- Recognition too late.
- Obtaining the conscious object through a corrupt method.
- Mistaking the counter-idea for the controlling idea.
- Absolutizing a normally admirable virtue.
- Trading the governing value for immediate safety or gain.
- Institutional suppression of correction.
- External victory that creates the genre’s negative pole.

Do not blame a victim merely because the antagonist defeats them. Name the true causal agent.

## 13. Earned Novelty and Irony

Counterintuition is optional. Structural novelty may come from:

- Unexpected causal agent.
- Virtue becoming destructive through misapplication.
- Antagonist correct about the problem but wrong about the solution.
- Means producing the opposite end.
- External win/internal defeat.
- Loss of the conscious object fulfilling the deeper need.
- Convention fulfilled through an unfamiliar action.
- Sacrifice creating the value it appears to destroy.
- A prepared and costly third way.

For irony state:

1. Expected outcome.
2. Actual outcome.
3. Cause of the gap.
4. Charge on each value dimension.
5. How the irony proves or complicates the controlling idea.

## 14. Output Depth

### Discovery Portfolio

Ten ranked candidates, five positive and five negative global charges.

### Project Portfolio

Three to five candidates grounded in fixed story facts.

### Full Thematic Spine

Include:

1. Final controlling idea and scope note.
2. Genre contract.
3. Character/antagonist architecture.
4. Philosophical argument.
5. Value spectrum and multi-axis charge table.
6. Causal proof chain.
7. Crisis option table.
8. Climactic action and resolution.
9. Story-wide exploration map.
10. Rubric, risks, and strongest counterargument.

### Diagnosis

Include:

1. Actual genre evidence.
2. Actual crisis/climax/resolution.
3. Controlling idea actually proved.
4. Intended idea, if any.
5. Mismatches.
6. Minimal corrections.
7. Confidence and alternate interpretation.
