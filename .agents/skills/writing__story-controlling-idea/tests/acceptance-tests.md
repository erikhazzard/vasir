# Acceptance Tests

Use these as behavioral tests after any edit to the skill.

## 1. Action Value Lock

**Input:** “Generate controlling ideas for an Action Adventure — Environment story.”

**Pass:** Every controlling idea’s Value is Life or Death. Harmony with nature, humility, respect, knowledge, or freedom may appear only in the Cause or secondary charges.

**Fail:** “Freedom is achieved by respecting nature.”

## 2. Crime Value Lock

**Input:** “A journalist exposes a corporate murder cover-up. Global genre: Crime.”

**Pass:** Value is Justice/Injustice; truth and journalism are the causal means.

**Fail:** “Truth triumphs when journalists are brave.”

## 3. Society Value Lock

**Input:** “Political revolution against a corrupt regime.”

**Pass:** Value is Power/Impotence and the resolution states where power actually goes.

**Fail:** “Justice wins when the rebels unite.”

## 4. Western Value Lock

**Input:** “Vengeance Western.”

**Pass:** Value is Freedom/Subjugation. Justice and vengeance shape the Cause.

**Fail:** “Justice is restored when the gunslinger kills the murderer.”

## 5. War Value Lock

**Input:** “Anti-war story in which the unit wins the battle by executing civilians.”

**Pass:** The likely global charge is Dishonor despite military victory.

**Fail:** “Victory is achieved through ruthless necessity.”

## 6. Performance Value Lock

**Input:** “A musician deliberately loses a contest rather than imitate the judge’s preferred style.”

**Pass:** Respect may be positive despite competitive defeat; the Big Performance proves the charge.

**Fail:** Treating Success/Failure as the global value.

## 7. Horror Secondary Sanity Value

**Input:** “Psychological Horror about paranoia.”

**Pass:** Sanity/Madness may be tracked secondarily, but the global controlling idea resolves Life/Death/Damnation if Horror remains global.

**Fail:** Replacing the global Value with “clarity.”

## 8. Hybrid Genre

**Input:** “A Western murder mystery.”

**Pass:** The system identifies whether the global ending is the Exposure of the Criminal or the Big Showdown that frees the community, declares one global genre, loads both references, and uses only the global genre’s Value.

**Fail:** Blending Justice and Freedom into one undefined Value.

## 9. Crisis vs. Climax

**Input:** “The hero must choose whether to sacrifice the witness.”

**Pass:** Labels this as Crisis, then states the actual irreversible action and its consequence.

**Fail:** Calling the choice itself the Climax.

## 10. Cause Specificity

**Pass:** “Justice is restored when the prosecutor discloses the fabricated evidence that secures her own conviction, making the system correct itself at the cost of her career.”

**Fail:** “Justice is restored through integrity.”

## 11. Negative Causality

**Pass:** Negative ending identifies the protagonist’s refusal, corrupt action, or institutional mechanism that causes the negative genre pole.

**Fail:** “Death wins because the villain is stronger.”

## 12. Philosophy Discipline

**Pass:** The philosophy field states an exact verified proposition that changes character action and includes a counter-position.

**Fail:** “Philosophy: Panpsychism” appended to an otherwise unchanged idea.

## 13. Genre Discovery Distribution

**Input:** A genre-only request for ten ideas.

**Pass:** Exactly five positive and five negative global charges, all on the same canonical value axis, with ten distinct causal mechanisms.

## 14. Core-Event Payoff

**Pass:** The final sequence fulfills the selected genre’s core event and resolves its conscious object of desire.

**Fail:** A secondary romance, investigation, or revolution takes over the climax without reclassifying the global genre.

## 15. No Version History

**Pass:** The model iterates internally and returns only final candidates.

**Fail:** Exposes draft 1, draft 2, and revision logs without request.
