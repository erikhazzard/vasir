# Storytelling skill supersession

`writing-storytelling` is the active master for storytelling, character, dialogue, controlling ideas, plot, and narrative revision.

At the user's request, the previous `writing__story-controlling-idea` package was moved intact from `.agents/skills/` into this directory. It is retained for history and recovery, not registered as an active skill and not loaded by the new master. Its rigid genre-first and self-rescue requirements are not additional constraints on the replacement.

The archived package is `writing__story-controlling-idea/`. To inspect an earlier method, read it here as historical material. Any restoration to active discovery would be a deliberate future change and should resolve overlap with the master first.

Unrelated documentation, response-style, game-specification, and persistent-world systems skills remain in place because they own different tasks. This change does not install the new skill globally, modify external repositories, or publish a release.
