# EVAL PLAN — THREE.JS OBSERVATORY INSTANCING PILOT

**Human Read:** This plan falsified an incremental performance benefit from `code__threejs-rapier-performance` in this matched Three.js instancing run. Both visually accepted Sol-xhigh candidates were topology-safe and effectively implemented the same hot path; their direct timing difference stayed inside calibrated noise. The topology guard itself was valid: it rejected the exact five-extra-full-scene-pass, five-extra-full-resolution-target, second-terminal-write mutation. This is a manual M4 precursor and one local desktop run, not a universal skill, mobile-performance, or supported `vasir eval` claim.

## 1) Unlock & Terminal Truth

- **Unlock:** The author can compare clean and skill-guided implementations of the same bounded Three.js instancing task without confusing a prettier generation, a different starting architecture, or a visually degraded result for a performance win.
- **Terminal truth:** From one immutable fixture and task, two fresh Sol-xhigh agents produce runnable artifacts; each is compared blind to an author-approved visual oracle before topology and local performance evidence are interpreted.
- **Authority environment:** The author's local machine, its installed Chrome build, and the exact captured source/task/treatment snapshots.
- **Subjective component:** The author alone accepts the oracle and later decides visual non-inferiority for each anonymous candidate.
- **Claim boundary:** Directional evidence for this fixture and treatment snapshot only; no automated aesthetic approval, aggregate model claim, device generalization, or M4 CLI-support claim.

## 3) Proof Stack

First produce deterministic portrait and landscape media from the look-only oracle and prove their artifact health. Stop at the author gate and hash the accepted basis. Then create one deliberately uninstanced, topology-safe task fixture, prove its artifact health, and stop for human equivalence review against that oracle. Only after both visual bases are accepted may matched clean and skill-treated Sol-xhigh sessions run from independent identical copies. For each anonymous candidate, contract and visual non-inferiority come before render-topology inspection, and topology comes before interleaved local measurement. A candidate rejected visually is disqualified; its lower workload is not a win.

**Stack blind spot:** This pilot does not measure mobile GPUs, thermal throttling, battery, long-session memory behavior, WebXR, Rapier, or generalization beyond one task.
