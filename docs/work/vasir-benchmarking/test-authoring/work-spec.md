# Test authoring from production code

**North Star:** A reader can compare how four model settings write useful new tests, and whether the testing skill improves those tests, in one standard benchmark table with inspectable native JavaScript.

## Request and scope

The user requested a separate from-scratch benchmark while preserving the existing test-suite improvement benchmark. Use the private backend's Redis-backed work queue: a recent, bounded production capability with real infrastructure. Existing queue tests are private calibration material, never author input. This measures service-boundary integration test authoring, not browser E2E, whole-repository exploration, or general model superiority.

## Contracts

- C-001: Four exact settings, each with Minimal and Skill, one fresh attempt per arm. The source, task, output envelope and runtime are identical; the complete current testing skill is the treatment.
- C-002: Native output is immutable. Two healthy runs and six predeclared source faults test whether assertions distinguish real behavioral failures. No source edits, fake queue implementations, or faults exposed to authors.
- C-003: Two blinded reviewers grade seven craft dimensions from 0 to 1, with line evidence. The user resumed Opus before either review started, allowing one eight-suite batch per reviewer. Opaque domain identifiers receive zero semantic-naming credit; headers, real journeys, independent oracles and unnecessary scaffolding remain explicit criteria.
- C-004: One additive /100 score: fault detection 25, behavioral coverage 20, independent assertions 15, boundary fidelity 10, semantic naming 10, domain structure 5, clarity 5, maintenance economy 5, runnable tests 5. No caps or preservation component. Freeze before generation; unresolved infrastructure does not become a numeric failure.
- C-005: Publish a separate Writing new tests table with exact raw JS, reviews and method. Keep existing improvement data and results unchanged. Report all attempts, disagreements and actual usage; no retries or selection for a preferred winner.
