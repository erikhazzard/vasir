# Backend test-suite quality benchmark

Measures the suite an agent leaves behind: independent assertions, appropriate test layers, domain clarity, useful protection and economical maintenance. Useful units are welcome; tautological checks and redundant machinery are defects.

## Current assessment

The [live report](https://vasirbenchmark.com/benchmark-report.html#backend-testing) compares Minimal instructions with the complete current skill on one player-saves maintenance case. Four exact model settings contribute one trial per arm: Astra ultra, Astra xhigh, Sol 6.1 xhigh and Opus 5.5 xhigh. Task, source, tools and budgets match across conditions.

The two-reviewer instrument grades all eight retained suites and every retained spec file on seven 0–1 dimensions: assertion quality (25%), behavioral coverage (20%), test-layer fidelity (15%), domain structure (10%), clarity and diagnosis (10%), maintenance cost (10%), and semantic variable names (10%). `taste-rubric.json` fixes the definitions, anchors, weights and naming-zero rule. An opaque domain-bearing identifier zeros semantic naming for its affected file and suite; the other dimensions keep their scores.

Each suite total is calculated from its own weighted dimensions, then averaged across reviewers. File totals remain explanatory and never determine suite totals. Original ratings, reasons, source citations, reviewer differences and explicit audit qualifications remain inspectable. The public overall score multiplies each reviewer’s weighted total by 100 and applies that reviewer’s saved preservation finding: lost material protection caps it at 49, zero meaningful runnable coverage scores zero, and unresolved required evidence remains unscored. Average the two derived reviewer scores. This combination was adopted after the reviews at the user’s request; raw ratings remain unchanged. Inspect run shows exact final JavaScript spec files, seven 0–1 dimension ratings and the score calculation. Both reviewers completed the panel; a user-requested Astra retry retains its initial timeout and unknown usage in the operational record. This is an exploratory assessment of one known case, not a general effectiveness estimate.
