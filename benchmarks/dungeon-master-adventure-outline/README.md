# Dungeon Master: Adventure outline

Thirty-two fresh Astra Ultra outlines compare the exact primary prompt `create an outline for TTRPG adventure` and five independently written transfer prompts with and without explicit invocation of a frozen Dungeon Master skill. Six primary repetitions and two per transfer task produce sixteen matched pairs. Two fresh, counterbalanced Astra Ultra judges assess each intact pair using six equal 0–5 dimensions.

Read [methodology.md](methodology.md), [judge-rubric.md](judge-rubric.md), [benchmark.json](benchmark.json), and [RUNBOOK.md](RUNBOOK.md). This benchmark is separate from Storytelling and excluded from Overall. Planned calls and implemented pages do not establish completed evidence or live publication.
